# XScope

XScope 是一个本地优先的 X/Twitter 浏览器工具箱。第一版提供“用户热度”功能：打开一个 X 用户主页后，在页面右侧显示一个侧栏，扫描当前页面逐步加载的公开推文，并按点赞、回复、转发或浏览量查看热门内容。

## 当前版本：v0.1.1

## 第一版功能

- 自动识别 `x.com/<用户名>` 和 `twitter.com/<用户名>` 用户页面
- 在网页右侧显示可收起侧栏
- 如果安装扩展前已经打开 X 页面，点击工具栏图标会自动补注入页面脚本
- 自动向下滚动并去重收集推文
- 本地缓存，不使用 X API、不上传推文、不读取 Cookie
- 按点赞、回复、转发、浏览量排序
- 默认只展示原创推文，也可以切换查看回复和转发
- 展示扫描数量、最早日期和上次扫描时间
- 点击结果直接打开原推文

## 重要限制

这是一个免费、尽可能本地化的“页面扫描版”，不是官方全量历史数据接口。它只能收集 X 页面实际加载出来的内容，网络慢、X 的懒加载策略、页面结构变化都可能影响结果，因此侧栏会明确提示扫描范围，不承诺“账号全部历史”。

当前每个账号最多缓存 1,000 条推文。扫描过程中可以点击“停止”，已经收集的内容仍会保存在本地。

## 本地安装

1. 下载或克隆本仓库。
2. 打开 Chrome、Edge、Brave 或其他 Chromium 浏览器的 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库目录。
5. 打开一个 X 用户主页，点击右侧 X 圆形按钮，再点击“扫描当前用户”。

如果点击工具栏图标没有立刻看到侧栏，先刷新 X 页面，再点击一次扩展图标；最新版也会尝试自动补注入脚本。

更新代码后，在扩展管理页点击 XScope 的刷新按钮即可重新加载。

## 隐私与安全

XScope 只申请 `storage` 权限，并只在 X/Twitter 页面运行。扫描结果存储在浏览器本地。项目不会主动读取 Cookie、密码或令牌，也不包含点赞、关注、评论等自动化操作。

X 的页面结构可能随时变化。如果扫描结果异常，请提交页面结构和浏览器版本信息，不要提交 Cookie、令牌或账号密码。
